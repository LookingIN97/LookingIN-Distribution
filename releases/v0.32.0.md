# LookingIN 0.32.0

- Embedded the complete runtime combat catalog in the NativeAOT compute worker;
  the Unity plugin now reads live board sizes from game objects and delegates
  encounter support decisions to the worker without loading rule data.
- Collapsed the published managed boundary to one `LookingIN.dll`: Core and
  compute-contract source is compiled into its consumers, while their standalone
  DLLs, the external catalog/provenance files, and debug symbols are rejected by
  the artifact audit and omitted from deployment/release manifests.
- Advanced the incompatible worker protocol to version 11 and worker 2.0.0.
  The worker now returns its authoritative catalog identity during handshake and
  reports unsupported encounters per candidate instead of failing a whole batch.
- Replaced semantic operation names with numeric method identifiers and protects
  every named-pipe frame using per-session, per-direction AES encryption plus
  HMAC-SHA256 authentication; the session token is no longer repeated in JSON.
- Added a pinned Obfuscar 2.2.50 Release stage. Every Release build now treats
  the ordinary compiler output as an intermediate, writes only the obfuscated
  plugin to `artifacts/LookingIN`, preserves the BepInEx/Unity/Harmony callbacks
  needed at runtime, strips debug information, and fails closed if protection or
  artifact auditing does not pass.
