# LookingIN 0.35.0

- Replaced the worker's directly extractable gzip JSON combat catalog with a
  deterministic private binary format using fixed field order, repeated-string
  references and compression, then authenticated and encrypted it with
  build-paired AES-GCM. The worker rejects tampered, substituted, wrongly keyed
  or stale generated catalogs.
- Replaced the complete plugin-to-worker JSON protocol with a hand-written
  binary TLV codec. Protocol version 12 derives opaque method IDs, field IDs,
  frame magic and KDF material per version, removes JSON source-generation
  metadata, and exposes bounded stable error codes instead of exception text.
  The incompatible worker boundary is now version 3.0.0.
- Bound published workers to the protected plugin hash, release PairId, game
  process and installation layout, The Bazaar executable and global manager
  hashes, and the unique paired Addressables catalog files. A game content or
  plugin change now requires an explicit developer binding update and rebuild.
- Restored NativeAOT's default managed-code section merging for the worker and
  updater while retaining strict PE/ELF, CLR metadata and protocol-leak audits.
